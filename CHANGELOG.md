# Changelog

### Added
- Universal responsive playback experience
- Foldrone CC Engine
- Dedicated subtitle loading
- Subtitle provider discovery
- Playback speed cycling
- Adaptive audio and video mode controls
- Audio-only visualizer
- PWA support
- Foldrone Play welcome tone

- Compact icon-first controls on larger and landscape layouts
- Centered transport controls
- Mute/unmute visual state
- Pause/play alignment
- Foldrone Play landing identity
- Foldrone Play mark as media artwork
- Cinematic preparation and playback experience

### Security

- Content Security Policy
- HSTS
- Referrer Policy
- Permissions Policy
- X-Content-Type-Options
- X-Frame-Options
- Cross-Origin policies
- No provider API credentials in client code

Earlier internal iterations are intentionally not included in this public baseline.
